# Central Storage Network

The Central Storage Network is a Minecraft plugin that allows players to create a craftable storage computer block with a custom interface for managing items across a network. It includes storage disks, network cables, and a wireless remote, providing a comprehensive solution for item storage and organization in Minecraft.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/CentralStorageNetwork/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server.

## Use

1. Craft the storage computer block using the recipe:
   ```
   III
   ICI
   III
   ```
   Where `I` is an iron ingot and `C` is a chest.

2. Craft storage disks using the recipe:
   ```
   DDD
   DGD
   DDD
   ```
   Where `D` is a diamond and `G` is a gold ingot.

3. Craft network cables using the recipe:
   ```
    S
   S S
    S
   ```
   Where `S` is a string.

4. Craft the wireless remote using the recipe:
   ```
    R
   RCR
    R
   ```
   Where `R` is a redstone dust and `C` is a compass.

5. Place the storage computer block and connect it to storage disks and network cables to create a storage network.

6. Use the wireless remote to access the storage interface from anywhere.
